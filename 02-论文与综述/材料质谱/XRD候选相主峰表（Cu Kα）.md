## 最容易“打架”的峰区

```markdown
- 30° 附近：
  Magnetite / Maghemite / NiFe2O4 / Titanomagnetite / Titanomaghemite

- 35.5° 附近：
  Magnetite / Maghemite / Hematite / NiFe2O4 / 含 Ti 尖晶石 / Ferrihydrite（宽峰）

- 43°–45° 附近：
  γ-Fe / Magnetite / Maghemite / NiFe2O4 / Fe3C / α′-Fe / (Cr,Fe)23C6

- 57°–63° 附近：
  Magnetite / Maghemite / NiFe2O4 / Hematite / 含 Ti 尖晶石
```

## 如果是 316Ti 在 LBE 腐蚀后的样品，优先建议先对这几组

```markdown
1. γ-Fe：43.5, 50.7, 74.7
2. Magnetite：30.1, 35.5, 43.1, 57.0, 62.6
3. Maghemite：30.2, 35.6, 43.3, 57.3, 62.9
4. NiFe2O4：30.3, 35.7, 43.4, 57.3, 62.9
5. Hematite：24.1, 33.1, 35.6, 49.5, 54.1, 62.4
6. Goethite / Lepidocrocite：看 21.2 / 26.1 / 14.2 / 27.0 这些低角峰
```
